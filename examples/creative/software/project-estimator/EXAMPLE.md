# Synthetic calculator example

This implements hours × hourly rate, with source, a self-contained preview and usage instructions. No live customer, payment or profit is claimed.

[manifest.synthetic.json](manifest.synthetic.json) comes from the real integrated services/worker/Docker verification using explicitly local PayPal and model HTTP fixtures. Every file hash matches these originals. Cost observations are fixture usage and remain provisional; they are not a live invoice. The checks execute the delivered JavaScript in the isolated container, including an intentionally wrong first design followed by one separately funded repair.
